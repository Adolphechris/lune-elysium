# Feuille de route LUNE

## Phase 0 — Fondation
Objectif : poser la mission, les principes et le socle de LUNE.

Réalisé :
- dépôt LUNE créé
- mission définie
- architecture initiale posée
- scanner automatique du dépôt principal
- landing page de démonstration

## Phase 1 — Observation automatique
Objectif : faire de LUNE un observateur vivant du projet principal.

À faire :
- scan récursif des modules
- capture de la hiérarchie des dossiers
- classification des types de contenus
- identification de la logique de projet
- comparaison du plan avec l’état réel

## Phase 2 — Gouvernance et audit
Objectif : transformer les observations en information exploitable.

À faire :
- définir les états de tâches
- calculer le niveau de progression
- détecter les oublis et les faux terminés
- classer les risques et anomalies
- produire les recommandations

## Phase 3 — Contributeurs et métadonnées
Objectif : rendre visible qui a fait quoi, avec quel outil, à quelle date.

À faire :
- capturer les métadonnées d’éditeur
- tracer les modifications
- associer chaque contribution à une tâche
- enregistrer la preuve de validation

## Phase 4 — Conseil conversationnel
Objectif : donner à l’utilisateur un assistant de projet vivant.

À faire :
- moteur de synthèse
- interface de question-réponse
- résumé d’état
- vue par priorité et jalon
- recommandations orientées action

## Phase 5 — Production du système
Objectif : transformer LUNE en outil opérationnel de gestion du projet.

À faire :
- UI d’administration
- API de données
- données de mémoire persistantes
- intégration avec le dépôt ELLYSIUM
- dashboard d’audit final

## Critère de sortie de la phase 1

LUNE doit pouvoir dire automatiquement :
- quel est le projet observé
- quelles sont ses dimensions
- ce qui est déjà documenté
- ce qui est touché par le code
- ce qui reste à organiser
- où sont les zones de risque et de priorité
